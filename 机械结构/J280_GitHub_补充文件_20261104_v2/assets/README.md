# 展示素材

本补充包没有复制现有图片或视频。首次上传建议只选：

1. 一张清晰的系统实物总览图。
2. 一张与源码版本一致的系统结构图。
3. 少量上位机界面或实验结果图。
4. 一个演示视频播放链接。

建议文件名使用简短、稳定的英文名，例如 system_overview.png、architecture.png。放入文件后，再在根 README 中增加相应图片引用；当前没有设置指向缺失图片的占位链接。

| 素材 | 实际文件或链接 | 对应版本/说明 |
|---|---|---|
| 实物总览 | 待维护者填写 | 待填写 |
| 系统结构图 | 待维护者填写 | 待填写 |
| 演示视频 | 待维护者填写 | 待填写 |

完整视频优先用播放链接；多个剪辑过程版无需全部放进源码仓库。
