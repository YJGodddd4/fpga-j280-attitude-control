## 历史报告如何使用

原工程随包的编译、等价验证和上位机离线结果可以作为历史证据保留，但应标明来源版本与日期。已有 hardware_tested=false 或 hardware_validation=false 的记录不能写成“实机验证通过”。

参考工程的仿真入口还依赖其选择的仿真器/运行时。部分旧入口硬编码本机 Python、Node 或 WASM 路径；部分历史测试依赖 reference_input/ 等旧文件。需先整理环境和输入，不能承诺全部 tests/ 在新电脑或 GitHub CI 中直接通过。

v9.4 原回归样例位于 host/monitor/records/。本包只在 .gitignore 放行已确认的一个样例；缺少其他旧配置样例可能产生跳过项。通过项、失败项和跳过项应分别记录。

## 实验数据记录

位置误差、ADC量和角度量的单位/尺度不同；不要未经说明直接互换。只统计选定运行阶段，说明启动、停机、故障与断段的处理方式。保留原始数据，并将统计过程与输出结果对应到同一固件、配置和时间范围。
