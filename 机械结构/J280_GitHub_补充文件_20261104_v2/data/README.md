# 实验数据

这里放入你选定公开的实验CSV及必要的诊断/事件配套文件，不保存每一次运行产生的全部记录。原有回归测试需要的样例应留在测试读取的原位置，不能仅移动到这里。

每组数据请同时说明：

| 字段 | 内容 |
|---|---|
| 文件名 | 待填写 |
| 日期与实验阶段 | 待填写 |
| Git提交/固件SHA256/CF | 待填写 |
| 板卡、接线、控制模式 | 待填写 |
| 参考轨迹与参数 | 待填写 |
| 变量、单位和缩放 | 待填写 |
| 采样/遥测周期 | 待填写 |
| 时间区间、断段和剔除规则 | 待填写 |
| 同名诊断/事件文件 | 待填写 |
| 统计方法与输出 | 待填写 |

不要把示意数据写成实测结果；也不要将ADC计数未经标定直接当作角度。若文件过大，可提供数据集链接，并记录校验值与获取方式。
